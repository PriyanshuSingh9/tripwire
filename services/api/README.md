# TraceAML API (`services/api`)

uv-managed FastAPI service. Python >= 3.12. The single application entrypoint
is `api.app:app` (`services/api/src/api/app.py`).

## Setup

Run these commands from the repository root:

```sh
uv sync --project services/api
uv run --project services/api fastapi dev services/api/src/api/app.py   # or: make dev-api
```

Dev tools are in the `dev` group:

```sh
uv run --directory services/api ruff check .     # or: make lint-py
uv run --directory services/api pytest -q        # or: make test-api
```

The FalkorDB integration test writes a disposable `agentapi-test` graph to
`localhost:6379` and is skipped when FalkorDB is unreachable.

The API depends on the local `graph/` project. It reads the ignored
`artifacts/runs/hi-small-v8/baselines/inference_scores.parquet`,
`baseline_config.json`, and `baseline_metrics.json` artifacts generated by the
ML commands in the repository README. It fails closed if score columns include
labels, split assignments, or typology fields.

## Container

Build from the repository root (the graph package must be in the context):

```sh
docker build -f services/api/Dockerfile -t traceaml-api .   # or: make api-image
docker run -p 8000:8000 -e TRACEAML_FALKORDB_HOST=host.docker.internal \
  -v "$PWD/artifacts:/app/artifacts:ro" -v traceaml-cases:/app/data traceaml-api
```

The image runs as a non-root user, sets `TRACEAML_REPOSITORY_ROOT=/app`, and
stores cases at `/app/data/cases/cases.db`.

## Configuration

All settings use the `TRACEAML_` prefix and may come from the root `.env`.

| Variable | Default | Purpose |
| --- | --- | --- |
| `TRACEAML_FALKORDB_HOST` | unset | FalkorDB host; unset means `not_configured` |
| `TRACEAML_FALKORDB_PORT` | `6379` | FalkorDB port |
| `TRACEAML_GRAPH_NAME` | `traceaml` | Graph holding the replay transactions |
| `TRACEAML_GRAPH_QUERY_TIMEOUT_MS` | `5000` | Server-side timeout per graph query |
| `TRACEAML_GRAPH_POOL_SIZE` | `16` | Max pooled FalkorDB connections per process |
| `TRACEAML_CASE_DB_PATH` | `data/cases/cases.db` | SQLite case review store |
| `TRACEAML_PERFORMANCE_PATH` | `docs/benchmarks/iteration-2-performance.json` | Performance snapshot served by `/api/benchmarks` |
| `TRACEAML_REPOSITORY_ROOT` | detected | Base for relative artifact paths |
| `LLM_PROVIDER` | `none` | `gemini` enables the optional report agent (blank means off) |
| `LLM_API_KEY` | unset | Gemini API key; also read from `GEMINI_API_KEY`. Keep it in `.env` only |
| `LLM_MODEL` | `gemini-flash-latest` | Gemini model name or alias |
| `TRACEAML_AGENT_TOOL_TRANSPORT` | `mcp` | `mcp` routes the LLM agent's graph tool calls through the MCP server; `direct` bypasses it. `python -m api.mcp_graph` serves the tools over stdio |
| `LLM_TIMEOUT_SECONDS` | `30` | Wall-clock limit for the whole agent run |
| `LLM_MAX_TOOL_CALLS` / `LLM_MAX_ROUNDS` | `6` / `3` | Tool-call and model-round budgets |
| `LLM_MAX_OUTPUT_TOKENS` | `1500` | Output cap per model call |
| `LLM_PRICE_INPUT_PER_MTOK` / `LLM_PRICE_OUTPUT_PER_MTOK` | unset | USD per million tokens; cost is reported only if both are set |

Relative paths resolve against the repository root. Responses never include
hosts, ports, credentials, file paths, exception text, or dataset labels.

## Routes

- `GET /api/health` returns `{ "status": "ok", "falkordb": "available", "version": "0.1.0" }`;
  `falkordb` is one of `available`, `unavailable`, `not_configured`.
- `GET /api/alerts?limit=50&offset=0` returns a risk-ranked replay queue with
  timestamp and deterministic `allow`/`review` decision.
- `GET /api/benchmarks` returns the saved model metrics and the recorded
  performance snapshot.
- `POST /api/investigations` accepts a transaction ID and bounded depth, time
  window, and result limit. It loads the stored risk score, applies the
  validation-selected threshold, runs all approved FalkorDB tools
  concurrently, and validates the returned evidence references.
- `GET /api/cases`, `POST /api/cases`, `GET /api/cases/{case_id}`, and
  `POST /api/cases/{case_id}/review` manage analyst cases with an append-only
  review history.

The full request, response, and error contract is in `docs/contracts.md`. The
current report is deterministic; no LLM provider is configured.

## Performance notes

Score, threshold, and benchmark artifacts are cached per file version, and
the score artifact is preloaded at startup, so queue and benchmark reads do no
repeated file IO. Investigation tools share a pooled set of FalkorDB
connections and run concurrently: `trace_funds` and `inspect_counterparties`
start together, and the three pattern queries start once the anchor's account
keys are known. `evidence.query_duration_ms` is the evidence-phase wall time;
`evidence.tool_durations_ms` gives each tool's own time.
